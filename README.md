# 🌌 Portfolio — Ariunbolor Tsendsuren

A modern, single-page developer portfolio inspired by Brittany Chiang’s v4 design, rebuilt with **Next.js**, **Tailwind CSS**, and a custom **galaxy-themed UI**.  
The site focuses on clarity, performance, and subtle interactions rather than heavy animations or visual noise.

## ✨ Features

- Sticky two-column layout (desktop)
- Mobile-first responsive design
- Cursor-follow galaxy spotlight
- Clean typography & dark theme
- Experience, Projects, and Articles sections
- External links open in new tabs
- Lightweight and performant

## 🛠 Tech Stack

- **Next.js (App Router)**
- **React**
- **TypeScript**
- **Tailwind CSS v4**
- **CSS Variables** for theming
- **Lucide Icons**
- **Intersection Observer** for active navigation

## 🎨 Design Philosophy

- Inspired by minimal, content-first portfolios
- Dark theme optimized for long reading
- Subtle color accents (teal, violet, warm highlights)
- UI should feel calm, intentional, and distraction-free
